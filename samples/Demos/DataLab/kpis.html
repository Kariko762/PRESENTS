Three ways a page reads data

  • data-fis-field="client.shortName" — no script: the text is replaced when the field exists, otherwise the HTML default stays.
  • data-fis-count="kpis.tradesToday" — animated counter; data-fis-when="kpis.openBreaks" hides an element when the value is empty or zero.
  • FISDeck.data('kpis.notional', 0) — in script, with a fallback, then FISDeck.format.money() to render it in the client's currency.
